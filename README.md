# YT Loop 🎸

**Free A–B looping for YouTube.**

YT Loop is a simple browser extension that lets you repeat selected sections of YouTube videos.

Perfect for practicing guitar, learning languages, studying, dancing, and more.

## Features

- Set A and B points to loop any section of a video.
- Save multiple segments for each video.
- Control playback and looping with keyboard shortcuts.
- Use a draggable, resizable fullscreen panel.
- Export and import saved segments as JSON.
- English and Polish language support.
- Save preferences locally in your browser.
