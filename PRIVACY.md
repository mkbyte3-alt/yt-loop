# Privacy Policy — YT Loop

**Last updated: November 21, 2026**

YT Loop is a free browser extension that allows users to create and repeat selected A–B sections of YouTube videos.

## Data Collection

YT Loop does not collect personal information, require user registration, display advertisements, or use analytics or tracking technologies.

## Local Storage

The extension stores user preferences and saved A–B loops locally in the browser. This may include video identifiers, loop start and end times, selected colors, and extension settings.

This information is used solely to provide the extension's functionality. It is not transmitted to the developer's servers.

## YouTube Access

YT Loop accesses YouTube pages to interact with the video player, display its controls, and manage A–B playback loops.

## Import and Export

Users may manually export and import their saved loop data. Exported files remain under the user's control.

## Third-Party Websites

The extension may contain an optional link to an external donation service. Visiting that website is voluntary and subject to the service provider's own privacy policy.

## Changes to This Policy

This policy may be updated if the extension's functionality or data-handling practices change.

## Contact

For privacy-related questions, please use the contact information provided in the YT Loop GitHub repository.
